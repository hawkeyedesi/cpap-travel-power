# CPAP travel power

A small, independent static guide to running a CPAP (ResMed AirSense 11) on battery while travelling, with India as the lead example. No ads, no affiliate links.

Plain HTML/CSS, no build step. `build.py` is an optional helper that regenerates the pages from one file.

Live: https://hawkeyedesi.github.io/cpap-travel-power/
